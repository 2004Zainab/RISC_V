# RISC_V
A single-cycle, non-pipelined RISC-V (RV32I) processor core in Verilog, built from modular RTL components — ALU, control unit, register file, PC, immediate generator, and instruction/data memory — each with its own testbench, wired together in a top-level risc_v module implementing the full fetch-decode-execute-memory-writeback datapath.
